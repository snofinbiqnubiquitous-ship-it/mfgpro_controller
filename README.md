# QAD / MFG:PRO Modern Terminal

## 起動

- このフォルダでは `自作モダンターミナル.pyw` をダブルクリックして起動できます。
- `.pyw` を使用するため、コマンドプロンプトの黒画面（CLI）を一切起動せずに直接モダンGUIが立ち上がります。
- 同じフォルダの `.venv` がある場合、標準Pythonから自動的に切り替えます（pythonwを優先）。

Python と次のライブラリを使用します。既存環境がある場合はそのまま利用できます。

```powershell
python -m pip install -r requirements.txt
python "自作モダンターミナル.pyw"
```

今回作成したローカル仮想環境で起動する場合：

```powershell
.\.venv\Scripts\pythonw.exe "自作モダンターミナル.pyw"
```

`自作モダンターミナル.pyw`、`terminal_core.py`、`order_entry.py` は同じフォルダに置いてください。
社内サーバーへの接続には会社のVPN接続が必要です。現在のアプリは起動後に自動接続します。

## 注文入力

- Ctrlを単独で2回押すと、右側に注文入力パネルを表示／非表示にできます。「表示 → 注文入力」からも開閉できます。
- Ctrlの長押しやCtrl+Cなどの組み合わせでは切り替わりません。閉じても入力内容はアプリ終了まで保持します。
- 上部に顧客名・納品先・Required date・due date・Purchase Order・Remarks・SO commentを入力します。
- 日付はカレンダーから選択します。表示例は `2026/9/24 (木)`。初期値は当日です。
- 明細は製品名・巾・長さ・本数・価格の5列、最大5行。未使用行は空白にします。
- 顧客名・納品先と1行以上の明細が必要です。本数は正の整数、巾・長さは正の数、価格は0以上で入力します。
- RemarksとSO commentの初期値は空白です。Purchase Orderとコメント類は任意入力です。

「表示 → 注文入力の候補CSV」から、顧客名と納品先のCSVをそれぞれ選択できます。
ファイルパスを設定に保存し、次回パネルを開いた時も読み込みます。UTF-8（BOMあり／なし）とCP932（Shift_JIS）に対応します。
1列だけのCSVは見出しなしでも使用可能です。複数列の場合は先頭行に `顧客名`／`納品先` を指定してください。
同じCSVに両方の列を置き、それぞれのメニューで同じファイルを指定することもできます。空白と重複は除外します。
CSV未設定時も、ドロップダウンに直接入力できます。顧客と納品先の連動絞り込みは行いません。

### 送信ロジックの接続箇所

「送信」は入力チェック後、現在は注文内容をローカルの別画面に出力します。QADやGASには送信しません。
後で定めるロジックは `.pyw` の `TerminalApp._process_order_submission(payload)` に実装してください。
受け渡し内容は `customer_name`, `ship_to`, `required_date`, `due_date`, `purchase_order`, `remarks`, `so_comment`, `items`。
日付はISO形式、`items` は `product_name`, `width`, `length`, `quantity`, `price` を持つ配列です。
巾・長さ・価格は小数精度を維持した文字列、本数は整数です。入力値はログやファイルには保存しません。

## 画面と操作

- 上部：接続・キー送信・表示・カラーパレット・ログイン情報・ヘルプのメニューバーと、ログイン／切断ボタン。
- 中央：80〜132列 × 24行のターミナル。パネル領域いっぱいに文字を自動最大化（Auto Fit）し、上下左右均等にフィット表示します。
- 右側：F1〜F4、Enter、Space、Esc、Ctrl+F、Tab、Backspace、矢印キーの送信ボタン。
- カラーパレットメニュー：専用のカラーパレットダイアログを開き、標準テーマ（ライト/ダーク/グリーン/アンバー）やカラータイル、自由なカラーピッカーから配色を変更・保存可能。
- ログイン情報メニュー：ホスト名・ポート・ユーザー名・パスワードを安全に登録・ローカル保存（次回起動時も自動適用）。
- 表示メニュー：文字サイズ変更（画面サイズへの自動最大化 Auto Fit 対応）、カラーパレット・テーマ切替（ライト／ダーク／クラシックグリーン／カスタムカラーピッカー）。
- フォント設定：ターミナル等幅として「Cascadia Mono」や「Consolas」を優先し、罫線の上下左右の完全結合と半角カナ・漢字混じり行のピクセルアライメント補正を自動適用。
- ターミナル内のTabはQADへ送信します。Ctrl+Shift+Tabで上部ボタンへ移動できます。

ツールバーの表示名・キー割当は `terminal_core.py` の `TOOLBAR_GROUPS`、送信する制御文字は
`KEY_SEQUENCES` で指定します。複数フィールドを自動操作するマクロではなく、1クリックで
指定キーを1回送信するボタンです。F2〜F4などの役割はQADの画面に従います。

## 変更点と確認範囲（2026-09-17）

- 左サイドバーの接続操作を上部へ移動し、右側にキーツールバーを追加。
- Apple Designの指針に沿って、白・淡いグレーと角丸ボタンの明色UIに変更。
- 装飾的な見出し、起動時の説明文、常設の技術情報を削除。入力エラーは発生時のみ表示。
- 全画面の定期再描画から、変更のあった行だけの描画に変更。
- 通信処理をGUIから分離し、送信待ちで画面操作が止まらない構成に変更。
- 接続ごとに仮想画面とデコーダーを初期化。古い接続の通知は再接続先に反映しません。
- 引継ぎ設計書に従いCP932を使用し、受信境界で分割された日本語も継続してデコード。
- EnterはCR、F1はESC OP、ページ送りはスペースのみ。VT100の132列 × 24行を維持。
- 接続先・認証情報は既存設定を維持。QADのコマンド間待機を短縮する変更はしていません。

ローカルGUIの起動・通常サイズと最小サイズの配置・Pythonの構文を確認しました。
ユーザーの指定により、SSHログイン・実機キー送信・高速化の動作検証／速度測定は実施していません。
